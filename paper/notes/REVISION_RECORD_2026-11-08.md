## Additional issues found during implementation

- Original ID standardization used all shared paragraphs, including unused reference pages and the shared queried paragraph. All revised identification results were recomputed using only the current selected gallery references.
- The originally suspected attribute-score leakage does **not** affect the primary fusion temperature: it is fitted from identification scores only. This was verified in code rather than assumed from the initial review.
- Historical learned attribute weights were not fully nested and are excluded from the revised main evidence.
- Shared-text queries enter some impostor models in the exploratory both-predicted procedure. The reported comparison now uses only the 96 self-chosen-text settings. Those models can still include query-writer enrolment pages; the experiment is labelled descriptor agreement conditional on the enrolled cohort.
- The original control exceedance calculation already compared the handedness descriptor with control instances. The revised paper does not repeat the earlier review’s inaccurate suggestion that it only tested separate gains against zero. It adds direct paired writer intervals and describes exceedance fractions as designed-control comparisons, not calibrated exchangeable-null p-values.
- The corrected synthetic experiment uses exact baseline/oracle limits at 50%/100%, and a single query-level noise draw is reused across reference configurations.
- Reduced-gallery sensitivity refits normalization inside the selected gallery and explicitly retains fixed full-cohort ID-only calibration. Its class-specific results do not support a universal minority benefit.

## Remaining scientific and submission limits

The collection has 42 writers, one region, one photographic session, and one device. No new independent cohort or cross-session validation was available. Those limitations are explicit; broader forensic, causal and universal accuracy-threshold claims were removed rather than asserted without evidence. Conditional bootstrap intervals do not include full model refitting or new-gallery uncertainty.

The existing Elsevier two-column layout is retained. Accessible official PRL formatting guidance supports a seven-page manuscript and a maximum 200-word abstract; the live guide returned HTTP 403. Exact current upload/template requirements, authorship approval and any institutional ethics documentation remain author/submission responsibilities. No external submission, public release, DOI registration or author signature was performed.

The independent final domain read-through found no critical unresolved scientific contradictions in the revised PDFs. This validation record documents the checks performed; it is not a guarantee of literal absence of every possible error or journal acceptance.
